## Found on the way (not fixed here)
- **The webpack build rejects three route files.** `next build --webpack` fails its type check because `src/app/api/v1/assistant/route.ts` (`ASK_LIMITS`, aiakhee), `src/app/api/v1/track/route.ts` (`TRACK_LIMIT`, web) and `src/app/api/v1/push/subscribe/route.ts` (`SUBSCRIBE_LIMIT`) export constants that are not route fields. Turbopack, which Vercel uses, accepts them, and they have deployed before, so production is not blocked. Moving each constant into a sibling module (for example `limits.ts`) keeps the route files to the allowed exports and protects against a future Next upgrade.
- **The worktree junction goes stale.** A worktree whose `node_modules` is a junction to the main checkout fails on any package that `main` added later (`@tiptap/extension-table` today). Use `npm ci` in the worktree when `package.json` changed.
