# AI coordination log

Several Claude agents work on MESH at the same time. This file is how they stay out of each other's way and how the owner sees who did what. Live discussion happens in GitHub issue 13 ("Agent coordination"). This file is the durable record. Where things stand and what is next: `docs/HANDOFF.md`. Older entries: `docs/archive/AI-LOG-2026-11-08-to-09.md`.

## Rules for every agent
1. The standing instructions are section 1 of `docs/HANDOFF.md`. They bind every agent.
2. **Before you start anything:** `git fetch --all`, read this file and the latest comments on issue 13, then run `npm run overlap` (every open PR, who claimed it, and where open PRs overlap) and `npm run overlap -- --find <topic>` for the thing you are about to do. If someone has it, do something else or ask on issue 13.
3. **Claim where the tools can see it.** Push your branch and open a draft PR as soon as you start, with a first comment `Working on: <your name>, <what>`. To review a PR, first comment `Reviewing: <your name>` on it. Also update your row below and say it on issue 13. A claim in a chat, a scratchpad or an unpushed branch does not count.
4. **Respect claims, and do not merge your own work.** Do not work on or review a PR that someone else claimed in the last 6 hours. After that, comment `Working on: <your name>, takeover` before touching it, and say so on issue 13. **When your PR is done**, mark it ready for review (not draft) and comment `Ready to merge: <your name>`, with what you checked. **Overseer 1 verifies it and merges it** (owner decision, 10 Nov). Nobody else merges.
5. Never edit files in another agent's area. If you must, ask on issue 13 first and wait for an answer, or for 30 minutes of silence. naiifos is a person and not always on; work around them where you can.
6. **One guide per topic.** Before writing a guide or FAQ, search `main` (`grep -rn "slug: \"<slug>\"" src/server/seed/content`, and the titles) and the open PRs (`npm run overlap -- --find <word>`). `tests/seed-no-duplicates.test.ts` fails when two seed lists define the same slug or two guides share a title. A rewrite of someone else's guide goes in their file after asking on issue 13, or in `GUIDE_REWRITES_2026_11`.
7. **Live database:** run `npm run content:diff` (read only: what a full sync would add or change) before any full `npm run content:sync`, and prefer `--only=<slugs>`. Only the owner, or an agent the owner asks, writes to production.
8. After each push others should know about, add one line at the top of "Log" and a short comment on issue 13. Say what changed, what is half done, and anything you broke or reverted. Log lines older than a day move to `docs/archive/`.
9. A conflict in this file is always "keep both sides".
10. Every PR gets an automatic "Overlap with other PRs" comment when it shares a slug, a migration number or a source file with another open PR (`.github/workflows/pr-overlap.yml`). Settle it on issue 13 before either merges.
