## Rules for every agent
1. The standing instructions are section 1 of `docs/HANDOFF.md`. They bind every agent.
2. Before starting, read this file and the latest comments on issue 13, and run `git fetch --all` to see what others pushed.
3. Claim a task on issue 13 and in your row below before working on it, and push the change straight away.
4. Never edit files in another agent's area. If you must, ask on issue 13 first and wait for an answer, or for 30 minutes of silence. naiifos is a person and not always on; work around them where you can.
5. After each push others should know about, add one line at the top of "Log" and a short comment on issue 13. Say what changed, what is half done, and anything you broke or reverted.
6. A conflict in this file is always "keep both sides".
