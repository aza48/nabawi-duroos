# Other sources to mine (internal research list, 9 November 2026)

Internal only. **Never name any of these sources in public text** (house rule 2). They are leads: every fact must be checked against an official Saudi page (absher.sa, my.gov.sa, hrsd.gov.sa, moh.gov.sa, haj.gov.sa, iu.edu.sa) before it goes into a guide, and written in MESH's own words (house rule 4).

How this list was made: web searches in English, Arabic, Urdu, Indonesian and Malay on 9 November 2026; every scrape endpoint below was fetched with curl from this sandbox on that date unless marked "not verified". YouTube channel ids were read from the channel page (`"externalId"`) and the RSS was fetched at `https://www.youtube.com/feeds/videos.xml?channel_id=<id>`. Gap judgements come from `grep -liE` over `src/server/seed/content/*.ts` on the same day ("0 hits" means no file mentions the keyword).

Substack note: the archive API is `https://<name>.substack.com/api/v1/archive?sort=new&limit=50` and returns `{"posts":[...]}`. `offset=0` is rejected with a 400, so leave `offset` out on the first page and pass `offset=50`, `offset=100` after that. `https://<name>.substack.com/feed` carries full text of recent posts.
