TITLE: Comment Ouvrir et activer un compte Absher ? — GoMedine
PUBLISHED: 
MODIFIED: 

Les détenteurs de l’Iqama, y compris les personnes à charge des expatriés et les titulaires de visa de visite, peuvent créer un compte Absher, procéder à l’inscription et activer leur compte.
Note : Jawazat a récemment autorisé les personnes à charge des détenteurs d’Iqama, les ressortissants du CCG et les titulaires de visa de visite à s’inscrire sur Absher.
Inscription sur Absher
Pour créer un compte Absher :
Ouvrez le lien https://www.absher.sa/
Cliquez sur « Individus ».
Sélectionnez la langue « Anglais ».
Appuyez sur l’icône « Nouvel Utilisateur ? ».
Sur la page suivante, remplissez le formulaire d’inscription Absher en entrant les détails suivants :
Numéro d’ID : Numéro d’Iqama pour les expatriés et numéro de frontière pour les visiteurs.
Numéro de Mobile : Numéro de mobile saoudien.
Nom d’utilisateur en Anglais .
Mot de passe .
Adresse email .
Sélectionnez la langue préférée comme l’anglais .
Entrez le code de l’image .
Cochez la case pour confirmer les termes et conditions .
Appuyez sur « Suivant » pour l’inscription du compte.
Comment Créer un Compte Absher
Entrez le code de vérification reçu sur le mobile.
Félicitations, vous avez créé avec succès le compte Absher.
Poursuivez avec l’activation du compte.
Activer un Compte Absher
Il existe 3 méthodes différentes pour activer votre compte Absher après l’inscription :
1- Depuis l’application Nafath
Comment Activer Absher et Prendre Vos Empreintes Digitales Depuis l’Application Nafath en Ligne ?
2-Visiter le Bureau Jawazat
Vous pouvez visiter n’importe quel bureau Jawazat dans le Royaume ;
Prenez rendez-vous avec Jawazat avec le service :
Comment prendre rendez-vous auprès de Jawazat via Absher ?
Activer le numéro de téléphone portable du compte Absher.
Cherchez la fenêtre désignée.
Fournissez votre Iqama et UserID.
L’officier activera immédiatement votre compte Absher.
3- Machines d’Activation en Libre-Service
Il y a plus de 420 machines d’inscription Absher en Arabie Saoudite, placées dans différents centres commerciaux et bureaux gouvernementaux pour activer le compte.
Localisez la machine d’activation en libre-service la plus proche.
Sélectionnez la langue « Anglais ».
Entrez le numéro d’Iqama.
Scannez vos empreintes digitales.
Entrez le numéro de mobile enregistré avec Absher.

Entrez le code sms reçu sur votre mobile, félicitation vous avez ouvert votre compte
Conclusion
La création et l’activation d’un compte Absher sont des processus essentiels pour les expatriés et les visiteurs en Arabie Saoudite. Suivez ces étapes pour une expérience sans tracas.
FAQ
Q1 : Qui peut créer un compte Absher ?
R1 : Les détenteurs d’Iqama, les personnes à charge des expatriés, et les titulaires de visa de visite.
Q2 : Où puis-je créer un compte Absher ?
R2 : Sur le site https://www.absher.sa/ .
Q3 : Quelles langues sont disponibles pour l’inscription Absher ?
R3 : Anglais et Arabe.
Q4 : Quelles informations sont nécessaires pour l’inscription ?
R4 : Numéro d’ID, numéro de mobile, nom d’utilisateur en anglais, mot de passe, adresse e-mail, et préférence linguistique.
Q5 : Comment activer mon compte Absher ?
R5 : Visitez un bureau Jawazat ou utilisez une machine d’activation en libre-service.
Q6 : Y a-t-il des machines d’activation Absher en Arabie Saoudite ?
R6 : Oui, il y en a plus de 420 dans divers emplacements.
Q7 : Puis-je choisir la langue de l’interface sur les machines d’activation ?
R7 : Oui, vous pouvez sélectionner « Anglais ».
Q8 : Que faire si je reçois un code de vérification ?
R8 : Entrez le pour terminer l’inscription de votre compte.
