TITLE: Comment obtenir un e-visa pour Oman pour les résidents d’Arabie saoudite ? — GoMedine
PUBLISHED: 
MODIFIED: 

Oman n’offre plus de visas à l’arrivée aux résidents du CCG et aux titulaires d’Iqama saoudiens. Au lieu de cela, les résidents du CCG doivent demander un e-visa omanais comme expliqué ci-dessous.
Pays du CCG : Arabie Saoudite, Émirats Arabes Unis, Qatar, Koweït.
Exigences pour le e-Visa d’Oman
Pour demander un e-visa omanais en tant que titulaire d’Iqama saoudien ou résident du CCG, vous devez avoir ce qui suit ;
Profession éligible (liste des professions ci-dessous).
Passeport avec une validité de 6 mois.
Iqama numérique avec 6 mois de validité.
Photo personnelle.
Le voyageur doit entrer à Oman directement depuis un pays du CCG.
Frais de visa pour Oman : 5 OMR ou 50 SR.
Validité du visa pour Oman : 28 jours.
Étape 1 : Enregistrer votre compte
Si vous remplissez toutes les exigences expliquées ci-dessus, vous devez enregistrer un compte sur le site web de la Police Royale d’Oman.
Ouvrir le site web .
Cliquer sur le bouton « Enregistrer un nouvel utilisateur ».
Remplir le formulaire d’inscription en entrant votre email, nom complet, numéro de téléphone et mot de passe.
Activer le compte en cliquant sur l’email reçu.
Étape 2 : Demander un e-Visa pour Oman
Après avoir enregistré votre compte sur le site web de la Police Royale d’Oman.
Ouvrir le site web du eVisa d’Oman : https://evisa.rop.gov.om/en/home .
Cliquer sur « Demander un visa touristique ».
Se connecter à votre compte récemment créé.
Cliquer sur « Demander un visa ».
Sélectionner « Demander un visa non parrainé » parmi les options.
Choisir votre nationalité.
Êtes-vous un résident du CCG ? « Oui ».
Sélectionner le pays de résidence du CCG : Arabie Saoudite.
Étape 3 : Sélectionner le type de visa
Dans l’écran suivant, vous devrez choisir le type de e-visa pour Oman que vous souhaitez demander. Vous pouvez sélectionner l’une des options suivantes ;
Visa 29A pour résident du CCG disponible pour un résident du CCG qui est employé et dont la profession est indiquée dans la liste ci-dessous.
Visa 29B pour résident du CCG : Si vous emmenez votre famille résidente du CCG (personnes à charge) avec vous à Oman, vous devrez demander ce type de visa.
Étape 4 : Remplir le formulaire de demande de visa
Sur la page suivante, vous devez entrer les
détails du passeport du demandeur.
détails supplémentaires, tels que l’occupation, le nom de la mère et l’état civil.
Télécharger les documents requis comme expliqué ci-dessus.
Soumettre la demande de visa.
Étape 5 : Payer les frais de visa pour Oman Bientôt,
vous recevrez un email de la plateforme de e-visa d’Oman confirmant l’approbation du visa avec un lien de paiement.
Cliquer sur le lien de paiement et payer les frais avec votre carte de crédit ou de débit.
Frais de visa pour Oman : 5 OMR.
Délai de traitement du visa : 4 à 5 jours.
