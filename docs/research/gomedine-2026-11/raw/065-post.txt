TITLE: Paiement et enregistrement d’un contrat de location avec Ejar en Arabie Saoudite ? — GoMedine
PUBLISHED: 
MODIFIED: 

Afin d’accepter un contrat Ejar, téléchargez une copie du contrat de location de la maison, payez le loyer via le système Ejar ou annulez le contrat, chaque locataire doit s’inscrire auprès d’Ejar en Arabie Saoudite.
À partir du 15 janvier 2024, il ne sera plus possible de payer le loyer en espèces ou par virement bancaire. L’Autorité Générale de l’Immobilier a rendu obligatoire le paiement du loyer résidentiel uniquement via MADA ou SADAD.
Le ministère HRSD a annoncé qu’un contrat électronique Ejar serait requis pour renouveler l’Iqama

Création du contrat Ejar par le propriétaire Tout d’abord,
votre propriétaire vous demandera votre numéro d’Iqama et votre numéro de téléphone pour créer un contrat de location de maison dans le système Ejar.
Le propriétaire paiera les frais de 250 SAR et créera le contrat.
Dès que l’inscription électronique est terminée de son côté, vous recevrez une notification par SMS du système Ejar.
Si vous ne le rejetez pas, il sera automatiquement considéré comme accepté après 7 jours.
Comment s’inscrire à Ejar en Arabie Saoudite ?
Vous recevrez un SMS d’Ejar avec un lien d’invitation unique pour vous inscrire sur le site web d’Ejar. Gardez à l’esprit que vous ne pouvez vous inscrire que via ce lien.
Ouvrez le lien. Entrez un nom d’utilisateur et un mot de passe uniques.
Entrez le numéro d’Iqama.
Saisissez les codes de vérification reçus d’Ejar et du MOI.
Félicitations, vous vous êtes inscrit avec succès auprès du système Ejar en Arabie Saoudite.
Pour accepter le contrat Ejar pour la location de votre appartement, je vous recommande d’utiliser votre ordinateur portable/fixe.
Connectez-vous à votre compte Ejar : https://eservices.ejar.sa/ar/public/login
Cliquez sur le bouton « Commençons ».
Sur la page suivante, vous pourrez revoir le contrat.
Cliquez sur le bouton « Télécharger ».
Téléchargez le contrat Ejar et lisez tous ses termes.
Imprimez-le ou conservez-le en toute sécurité sur votre ordinateur.
Articles importants à examiner dans le contrat Ejar Article 12 : Assurez-vous que le montant du loyer et les modalités de paiement sont correctement indiqués.
Article 13 : Assurez-vous de lire le dernier point de la clause 13 du contrat Ejar où il est écrit « شروط إضافية ».
Modalités de paiement du contrat Ejar
Si vous êtes d’accord avec tous les termes et conditions, faites défiler la page jusqu’à la fin jusqu’à ce que vous voyiez le bouton « Accepter ou Rejeter ».
Cliquez sur le bouton « Accepter » uniquement si vous êtes d’accord avec les termes. Le MOI vous enverra un OTP pour l’authentification. C’est tout, vous avez accepté avec succès le contrat Ejar.
Téléchargement du contrat Ejar
Pour télécharger une copie de votre contrat de location via le site web d’Ejar ;
Connectez-vous à votre compte : https://eservices.ejar.sa/ar/public/login
Cliquez sur l’onglet « Contrats ».
Sélectionnez « Voir tous les contrats ».
Vous trouverez ici tous les contrats actifs.
Cliquez sur les 3 points. Sélectionnez « Voir le contrat » dans le menu déroulant.
Cliquez sur « Télécharger une copie du contrat » pour imprimer une copie du contrat de location d depuis le système Ejar.
Comment payer le loyer via Ejar ?
Payer le loyer via la carte Mada Pour payer l’Ejar/le loyer via votre carte Mada,
Connectez-vous à votre compte : https://eservices.ejar.sa/ar/public/login
Cliquez sur l’onglet « Tableau de bord ».
Trouvez le contrat et cliquez sur le bouton « Effectuer un paiement ».
À l’écran suivant, le système Ejar vous montrera le montant de l’acompte du loyer à payer.
Entrez les détails de votre carte Mada ou de débit pour payer le loyer.
Payer l’Ejar via SADAD
Pour payer l’Ejar/le loyer via la banque SNB en utilisant SADAD ;
Téléchargez l’application via PlayStore ou iTunes.
Connectez-vous à votre compte de banque en ligne.
Sélectionnez « SADAD ». Cliquez sur « Paiement SADAD ponctuel ».
Bénéficiaire : Agences gouvernementales.
Code Ejar SADAD : 153.
Numéro d’abonné : Numéro de contrat du site web d’Ejar.
Payer le loyer par virement bancaire ou en espèces
Si vous avez payé votre loyer par virement bancaire ou en espèces, vous devez demander un reçu via le site web d’Ejar.
Connectez-vous à votre compte : https://eservices.ejar.sa/ar/public/login
Cliquez sur l’onglet « Tableau de bord ».
Trouvez le contrat et cliquez sur le bouton « Demander un reçu ».
Entrez le montant payé.
Méthode de paiement : Banque ou espèces.
Date de paiement : La date exacte du paiement.
Après cela, le propriétaire vous délivrera un reçu pour le paiement du loyer via le système Ejar.
Une amendes pour ne pas s’inscrire à Ejar de 25 000 SAR pour le propriétaire s’il n’est pas inscrit au système Ejar. Le permis de l’agent immobilier sera annulé pendant un an. Une amende de 1 000 SAR pour le propriétaire s’il ne télécharge pas de contrat. Par conséquent, il n’est pas nécessaire de leur payer 250 SAR pour l’inscription au contrat.
