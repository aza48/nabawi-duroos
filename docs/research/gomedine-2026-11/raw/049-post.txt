TITLE: Comment vérifier le statut de Huroob d’un employé en Arabie saoudite ? — GoMedine
PUBLISHED: 
MODIFIED: 

Conformément à la réglementation régissant la main-d’œuvre saoudienne, il est obligatoire pour les employeurs de notifier les autorités si leurs employés étrangers sont absents du travail. Ces individus signalés sont appelés Huroob.
Lorsqu’un expatrié est étiqueté comme Huroob, cela entraîne plusieurs sanctions, notamment l’annulation de leur statut d’Iqama, une interdiction de travailler en Arabie saoudite et l’interdiction d’entrer dans le pays avec un visa de travail.
De plus, l’expulsion et d’autres conséquences peuvent également s’appliquer. Étant donné l’impact significatif de ce statut, il est crucial de comprendre le processus de vérification du statut de Huroob. Continuez à lire pour obtenir plus d’informations sur la façon de procéder à une vérification du statut de Huroob.
Vérification du statut de Huroob en ligne est une procédure simple.
À l’heure actuelle, il existe deux méthodes disponibles pour déterminer si vous avez été assigné un statut de Huroob. Vérification de Huroob via le site web du ministère du Travail (MoL) Vous pouvez vérifier votre statut de Huroob sur le site web du ministère du Travail (MoL) en suivant ces étapes :
visitez le site web du MoL
insérez votre numéro de frontière,
votre numéro de résidence et votre numéro de passeport
sélectionnez votre nationalité
entrez le code de vérification captcha cliquez sur « Rechercher »
Votre statut d’emploi apparaîtra immédiatement.
Si cela indique que vous êtes absent du travail, cela signifie que vous êtes un Huroob.
Vérification de Huroob via Absher Il est également possible de vérifier votre statut de Huroob via le portail Absher :
visitez le site web d’Absher
connectez vous à votre compte Absher
cliquez sur « plus de détails » après vous être connecté
Vous devriez pouvoir voir votre statut d’emploi.
Si vous découvrez que vous n’êtes pas inscrit ou reconnu en tant qu’employé, il est possible que vous ayez été assigné un statut de Huroob.
