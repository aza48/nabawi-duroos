TITLE: Comment changer le numéro de mobile Absher en utilisant l’application Nafath ? — GoMedine
PUBLISHED: 
MODIFIED: 

Nous savons tous qu’Absher est un portail de services électroniques important en Arabie Saoudite, et c’est une exigence obligatoire pour accéder à la plupart des services gouvernementaux. Si vous devez mettre à jour votre numéro de mobile enregistré avec Absher, vous pouvez le faire en suivant les étapes décrites dans cet article.
Vous pouvez maintenant utiliser l’application Nafath pour mettre à jour votre numéro de mobile Absher sans avoir besoin de visiter le site Absher. Nous vous guiderons à travers le processus dans cet article.
5 étapes pour s’inscrire sur l’application Nafath
Étapes pour changer votre numéro de mobile Absher en utilisant l’application Nafath
Nafath est une application mobile introduite par le gouvernement saoudien, offrant un accès centralisé unifié à tous les prestataires de services tout en vérifiant l’identité de l’utilisateur. Ce qui la rend encore meilleure, c’est que vous pouvez mettre à jour votre numéro de mobile dans Absher en utilisant l’application Nafath sans avoir besoin d’une inscription à l’application. Voici comment :
Téléchargez l’application Nafath :
Visitez l’Apple App Store ou Google Play .
Téléchargez l’application Nafath sur votre appareil mobile.
Ouvrez l’application et réglez la langue sur l’anglais :
Après l’installation, ouvrez l’application Nafath.
Naviguez dans le menu des paramètres et sélectionnez « Anglais » comme préférence linguistique.
Accédez aux services des dispositifs d’auto-service Absher :
Sur la page des paramètres, trouvez l’option « Services des dispositifs d’auto-service Absher ».
Sélectionnez cette option pour continuer.
Choisissez « Mettre à jour votre numéro d’identité numérique (Absher) » :
Dans les services des dispositifs d’auto-service Absher, localisez et sélectionnez l’option « Mettre à jour votre numéro d’identité numérique (Absher) ».
Entrez votre numéro d’Iqama : Vous serez invité à entrer votre numéro d’Iqama.
Entrez les informations requises et cliquez sur le bouton « Suivant ».
Entrez votre nouveau numéro de mobile : Saisissez votre nouveau numéro de mobile (par exemple, 552576543) et cliquez sur « Suivant ».
Recevez et entrez le code d’activation : Vous recevrez un code d’activation sur votre nouveau numéro de mobile. Entrez le code comme indiqué pour continuer.
Vérification par empreinte digitale : Vous verrez un message qui dit : « Préparez-vous pour votre vérification par empreinte digitale. » Suivez les instructions à l’écran pour scanner les quatre doigts de votre main gauche en utilisant la caméra de votre mobile. Cliquez sur le bouton « Démarrer » pour lancer le processus de vérification.
Placez votre main gauche sur une surface plane et assurez-vous que la caméra capture les quatre doigts (à l’exclusion du pouce). L’application vérifiera rapidement vos empreintes digitales, généralement complétée en quelques secondes. Si la vérification échoue, essayez d’ajuster la mise au point de la caméra ou la distance entre vos doigts et la caméra.
Confirmation : Une fois la vérification terminée, vous recevrez un message confirmant que votre numéro de mobile Absher a été modifié. Vous devrez peut-être attendre environ 10 minutes pour que les modifications prennent effet.
