TITLE: Comment Annuler une carte Sim enregistrée sur votre Iqama ? — GoMedine
PUBLISHED: 
MODIFIED: 

Vous posséder une carte SIM à votre nom enregistrée sur votre iqama, et vous souhaitez la désactiver
Il y a trois façons de désactiver une SIM :
Visitez les centres de service client les plus proches de STC, Zain, Mobily, Virgin ou Lebara pour annuler la SIM.
Appelez la ligne d’assistance pour désactiver la SIM.
Utilisez le portail CITC et enregistrez une plainte en ligne pour supprimer les SIM indésirables enregistrées sous votre iqama.
Annuler la SIM en visitant les bureaux des compagnies de téléphonie mobile
Les centres de service client de toutes les compagnies de téléphonie mobile, y compris Mobily, Zain, STC, Virgin et Lebara, sont tenus d’annuler la SIM de leur réseau sur demande.
Vous devez indiquer le numéro de la SIM et présenter votre iqama pour la procédure d’annulation. Dans les 24 heures, la SIM sera annulée.
Note : La compagnie de téléphonie mobile peut également réémettre la SIM si vous souhaitez l’utiliser au lieu de l’annuler.
Appelez la Ligne d’Assistance pour Désactiver la SIM sur Votre Iqama
Vous pouvez également appeler le service client des compagnies de téléphonie mobile pour supprimer et désactiver les SIM enregistrées sur votre iqama.
Les numéros du service client des réseaux cellulaires opérant en Arabie Saoudite sont les suivants :
Ligne d’assistance STC : 900 / 114-555-555
Ligne d’assistance Zain : 959 / 059-000-0959
Ligne d’assistance Mobily : 1100 / 0560-101-100
Ligne d’assistance Lebara : 1755 / 057-600-1755
Ligne d’assistance Friendy : 166-000 / 057-116-6000
Ligne d’assistance Virgin : 1789
Pour les Clients Mobily
Si vous utilisez une SIM Mobily, vous devez composer le 1100 et suivre les codes suivants pour parler au représentant du service client afin de retirer la SIM Mobily de l’iqama.
Pour les plaintes, appuyez sur 9
Pour enregistrer de nouvelles plaintes, appuyez sur 1
Sélectionnez les plaintes concernant les services vocaux en appuyant sur 1
Pour annuler la SIM sur l’iqama, appuyez sur 4
La SIM sera désactivée dans les 5 jours ouvrables.
Utilisez le Portail en Ligne CITC pour Déposer une Plainte pour l’Annulation de la SIM
Sur la plateforme en ligne CITC, vous pouvez annuler la SIM de n’importe quelle compagnie de téléphonie mobile enregistrée sous votre iqama. Pour enregistrer la plainte, vous pouvez utiliser le portail en ligne ainsi que l’application CITC.
La procédure d’enregistrement de plainte pour annuler la SIM sur l’iqama est la suivante :
Installé et Ouvrez l’application CITC et connectez-vous en utilisant votre nom d’utilisateur et mot de passe du compte Absher.
Cliquez sur « Rapports ».
Cliquez maintenant sur le signe « + » pour créer un nouveau rapport.
Fournissez les détails avec les informations suivantes :
Choisissez le Type de Rapport Principal : Général
Choisissez le Type de Rapport : Divulguer des Informations Confidentielles Utilisateur
Choisissez le Numéro de Service : Sélectionnez le numéro de SIM que vous souhaitez retirer de votre iqama. Cliquez sur Suivant.
Sur la page suivante, entrez les détails suivants :
Fournisseur de Service : Sélectionnez le réseau cellulaire
Pour annuler la SIM STC sur votre iqama : Sélectionnez STC
Pour annuler la SIM Zain : Sélectionnez Zain
Pour annuler la SIM Mobily : Sélectionnez Mobily
Vous devez entrer quelques détails supplémentaires pour désactiver la SIM avec succès.
Numéro de Service : Sélectionnez le numéro de SIM que vous souhaitez retirer de l’iqama
Type : Divulgation « fuite » d’Informations
Preuve : Iqama
Description du Rapport : Donnez la raison pour laquelle vous souhaitez annuler la SIM. (par exemple, La SIM n’est pas sous mon usage, veuillez annuler le numéro.)
Maintenant, téléchargez l’image de votre iqama. Une fois téléchargée, cliquez sur « Envoyer à CITC ».
Le système affichera le message suivant,
Numéro de Demande : XXXXX Créé avec Succès.
