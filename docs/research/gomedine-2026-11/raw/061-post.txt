TITLE: Comment enregistrer et imprimer votre adresse nationale en Arabie Saoudite ? — GoMedine
PUBLISHED: 
MODIFIED: 

Vous pouvez effectuer l’enregistrement de l’adresse nationale soit via le compte Absher, soit par l’intermédiaire de Saudi Post. Voici la procédure pour chacun d’entre eux :
Comment imprimer la preuve de l’adresse nationale saoudienne ?
Vous avez besoin des informations suivantes pour l’enregistrement de l’adresse nationale saoudienne :
Numéro de bâtiment.
Nom du quartier.
Code postal de votre quartier. (pour Médine c’est 42316)
Liste des codes postaux en Arabie Saoudite 2023-2024
Nom de la ville.

Pour enregistrer votre adresse nationale avec Absher :
Connectez-vous à votre compte Absher https://www.absher.sa/
Cliquez sur « Mes Services ».
Sélectionnez « Services Généraux ».
Choisissez « Service d’Adresse Nationale ».
Imprimez l’adresse nationale avec Absher.
Sur la page suivante ;
Sélectionnez « Enregistrer une nouvelle adresse nationale ».
Entrez les détails de votre adresse.
Cliquez sur « Vérifier l’adresse nationale ».
Entrez le code OTP (sms) reçu sur votre téléphone portable.
Appuyez sur le bouton « Confirmer l’adresse ».
Enregistrement de l’adresse nationale pour les personnes à charge
Connectez-vous à votre compte Absher https://www.absher.sa/
Cliquez sur « Mes Services ».
Sélectionnez « Services Généraux ».
Choisissez « Service d’Adresse Nationale ».
Cliquez sur le bouton « Sélectionner ».
Sélectionnez la personne à charge en cliquant sur le bouton « + ».
Entrez le code OTP (sms) reçu sur votre téléphone portable.
Pour enregistrer votre adresse nationale par le biais du service Saudi Post ;
Ouvrez le site web https://eservices.splonline.com.sa/en/Registration/
Cliquez sur « Individuel » et continuez.
Sélectionnez « Résident ».
Entrez le « Numéro Iqama ».
Sélectionnez la date d’expiration de l’Iqama.
Entrez vos informations personnelles.
Acceptez les termes et conditions.
Cliquez sur « S’inscrire ».
Vérifiez maintenant votre numéro de téléphone portable pour l’enregistrement de l’adresse nationale, puis ;
Connectez-vous à votre compte https://eservices.splonline.com.sa/en/Account/Login
Cliquez sur l’icône du « menu » dans le coin supérieur gauche.
Appuyez sur l’option « Gérer les adresses ».
Sélectionnez « Adresse Nationale ».
Sur la page suivante, cliquez sur « Enregistrement de l’Adresse Nationale ».
À ce stade, vous devez saisir votre adresse saoudienne pour compléter l’enregistrement de l’adresse nationale ;
Informations sur l’emplacement : Location.
Type de résidence : Villa ou Appartement.
Saisissez la région, la ville, le quartier et le numéro de bâtiment.
Cliquez sur « Vérifier l’adresse ».
Confirmez le numéro de bâtiment à partir de la carte SPL.
Acceptez les termes et conditions.
Cliquez sur « Vérifier le téléphone portable ».
Vérifiez votre identité grâce au code OTP envoyé sur votre téléphone portable, et voilà ! Vous avez réussi à enregistrer votre adresse nationale en Arabie Saoudite.
Mise à jour/Changement d’une adresse nationale en KSA
Si vous avez déménagé ailleurs, vous pouvez facilement mettre à jour ou changer votre adresse nationale via le site web Absher ou SPL. Pour ce faire ;
Compte Absher Connectez-vous à votre compte Absher https://www.absher.sa/
Cliquez sur « Mes Services ».
Sélectionnez « Services Généraux ».
Choisissez « Service d’Adresse Nationale ».
Cliquez sur le bouton « Sélectionner ».
Appuyez sur « Modifier l’adresse nationale ».
Entrez la nouvelle adresse. Cliquez sur « Vérifier l’adresse nationale ».
Site web de Saudi Post Vous pouvez également modifier ou changer l’adresse nationale via le site web SPL. Pour cela ;
Connectez-vous à votre compte https://eservices.splonline.com.sa/en/Account/Login
Cliquez sur l’icône du « menu » dans le coin supérieur gauche.
Appuyez sur l’option « Gérer les adresses ».
Sélectionnez « Adresse Nationale ».
Sur la page suivante, cliquez sur « Enregistrement de l’Adresse Nationale ».
À ce stade, vous devez saisir votre nouvelle adresse saoudienne pour mettre à jour l’adresse nationale ;
Félicitations, vous avez réussi à mettre à jour/changer avec succès votre Enregistrement de l’Adresse Nationale. Il n’est pas nécessaire de mettre à jour l’adresse nationale séparément dans Absher.
Comment imprimer la preuve de votre adresse
De nombreuses banques et compagnies d’assurance exigent que vous vérifiiez ou imprimiez une preuve de votre adresse nationale enregistrée en Arabie saoudite. Voici comment procéder :
Pour vérifier et imprimer votre adresse nationale via Absher ;
Connectez-vous à votre compte Absher à l’adresse https://www.absher.sa/
Cliquez sur « Mes services ».
Sélectionnez « Services généraux ».
Choisissez « Service d’adresse nationale ».
Imprimez l’adresse nationale avec Absher.
Sur la page suivante, le système vous montrera l’adresse nationale.
Cliquez sur le bouton « Sélectionner ».
Appuyez sur le bouton : Imprimer la preuve de l’adresse nationale.
Cliquez sur le bouton « Imprimer ».
